# 外字注記辞書

青空文庫・外字注記辞書を機械可読にしたもの。`tools/extract_gaiji_chuki.rb` で
再生成できる（poppler-utils が要る）。

- 出典: <https://www.aozora.gr.jp/gaiji_chuki/gaiji_chuki.pdf>
- 版: 青空文庫外字注記辞書編集グループ・**改訂第八版訂正版（2011-08-06）**
- 利用条件: 青空文庫本体と同じ

```
ruby tools/extract_gaiji_chuki.rb gaiji_chuki.pdf crates/aozora-core/data
```

`id` は `p<ページ>-<ページ内連番>` で、上の版のページ付けに依存する。版を上げるときは
2 つの TSV を同時に作り直すこと。

## `gaiji_chuki.tsv` — 9203 エントリ

| 列 | 内容 |
|---|---|
| `id` | エントリの識別子 |
| `page` | PDF のページ番号（字形を目で確かめたいときの参照先） |
| `radical` / `strokes` | 部首（202 種）と画数 |
| `desc` | 注記の説明（`※［＃「口＋畢」…］` の `口＋畢`） |
| `jis` / `level` | 面区点と水準（4042 件） |
| `unicode` | U+ の値（4038 件） |
| `sub` / `sub_kind` / `sub_rule` | 代用してよい字・種別・規準番号（1139 件） |
| `cross` | 別部首への再掲（★）なら 1 |
| `glyph` | `1`＝輪郭あり / `pdf`＝PDF を見るしかない / 空＝符号位置で決まる |

`desc` が**両方向の結合キー**になる。読む側は「説明だけの注記」を字へ解決でき、書く側
（OCR など）は字から慣用の注記を引ける。

`sub_kind` の内訳は包摂適用 979・デザイン差 109・78互換包摂 29・統合適用 22。代用字は
1 文字とは限らず、37 件は代用字自体が外字注記になっている（`→［包摂適用 ※［＃「（冫＋
臣＋犯のつくり）／れんが」、第3水準1-87-58］］`）。

## `gaiji_chuki_glyphs.tsv` — 1045 字・1076 パーツ

**符号位置を持たない字だけ**、輪郭をベクタで持つ。面区点や U+ があれば字形は符号位置で
決まるのでフォントから描けるが、コードを持たない 1127 件——包摂適用・デザイン差・統合
適用、つまり「符号位置が同じで字形だけ違う」例示字形の問題そのもの——は辞書の字形が
唯一の情報源になる。

| 列 | 内容 |
|---|---|
| `id` | `gaiji_chuki.tsv` と同じ |
| `part` | パーツ番号（0 から） |
| `fill` | 色（下表） |
| `dx` | 先頭パーツからの水平位置 |
| `d` | SVG のパスデータ |

1 文字が複数パーツで組まれることがある（31 件）。単一のフォントに字が無く部品を並べて
いるためで、同じ `id` の行を `dx` だけ右にずらして重ねると 1 文字になる。

色は辞書の凡例がそのまま残る。

| `fill` | 意味 | 件数 |
|---|---|---|
| `rgb(100%, 0%, 0%)` | 包摂される字（底本の字形） | 832 |
| `rgb(0%, 100%, 0%)` | JIS X 0213:2004 で例示字形変更 | 165 |
| `rgb(50%, 50%, 50%)` | 参考掲載 | 78 |
| `rgb(0%, 67.8%, 93.7%)` | JIS X 0213:2004 で新規追加 | 1 |

## 取り込むときに引っかかったこと

- **表示字形は文字として取らない。** 外字は ToUnicode を持たない埋め込みサブセット
  フォント（GT2000・花園明朝など）で描かれ、pdftotext は BMP 外の字を別の字に取り違える
  （U+ を持つ 4021 件中 186 件が食い違い、うち 141 件が BMP 外）。正は注記本文であり、
  そちらはかなと常用漢字と ASCII だけなので確実に取れる。
- **制御文字。** 同じ理由で、字形は U+001E などの制御文字として出てくる。XML として
  不正なので落とす（位置しか使わない）。
- **`glyph=pdf` の 80 件は PDF に字形が入っていない。** 非埋め込みフォント
  （Ryumin-Light）で描かれており、アウトラインもテキストも取り出せない。ラスタライズ
  しても空白になる。この辞書からは復元できないので、`page` から現物を見るしかない。
- **`ページ数-行数` はプレースホルダ**（「ここに底本のページ-行を書く」という指示）
  なので取り除いてある。

## 使い道

変換経路には入れない。参照実装 aozora2html はこの辞書を持たないので、いま `※` で
出ている字を解決し始めると出力が変わり、オラクル（byte 一致）が悪化する。想定して
いるのは次の 2 つ。

- **診断** — 辞書に無い綴りの検出（入力ミス）、代用字の提案
- **生成側の支援** — 字から慣用の注記を引く逆引き（スキャン画像からの生成など）

コーパス全 17509 作品で、面区点を持たない注記は 7029 箇所 / 2735 種あり、`desc` で
引けるのは 3395 箇所 / 820 種（うち 770 種は字が一意に決まる）。引けないものは説明の
書き方の揺れが多く、正規化でさらに拾える余地がある。
