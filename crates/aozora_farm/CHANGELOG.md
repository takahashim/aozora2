# Changelog

## [0.2.0] - 2026-08-04

### 追加

- 青空文庫標準の Shift_JIS ＋ CRLF で本文を書き出すボタンを追加。
  Shift_JIS にできない文字があるときは、置き換えずにエラーになる。
- HTML も Shift_JIS で保存するように修正
- 文字種による色分けを追加。JIS X 0201（半角）・JIS 第3第4水準・JIS 外の 3 つを
  背景色で見分けられる。判定は打鍵に即追随する（表示範囲だけを見るため）。
- 診断の追加（エディタの波線）
  - `unclosed-accent` … 対応する `〕` が同じ行に無い `〔`（複数行アクセント／閉じ忘れ）
  - `non-x0208-char` … JIS X 0208 の外にあり、本来は外字注記で書くべき文字
  - `notation-in-header` … 記法が効かないヘッダ行に書かれた `《》` や `｜`
- 濁点付き片仮名（1-7-82〜85）の記法に対応
- 左ルビ（`［＃「…」の左に「…」のルビ］`）を追加

### 変更

- macOS のメニューを整理
- ヘッダと注記セクション（罫線で囲まれた凡例）を解析の対象から除外

### 修正

- HTML 保存の文字化けを修正
- 診断の誤爆を修正
- 開いて保存し直すだけで失敗する文書があったのを修正
- プレビュー／HTML 出力の互換性を改善
  - ぶら下げ（`［＃ここから…］`）の中で閉じるブロック、見出し行の扱い
  - 行の途中で開く・閉じる複数行ブロック（`［＃ここで字下げ終わり］` など）
  - 単独行の `［＃割り注終わり］` が外側のブロックまで閉じてしまう
  - ブロック形の段階指定で漢数字（`［＃三字下げ］` など）が読めない
  - 幅の数字が無い字下げ・字詰め、空の範囲形
  - ルビの親文字の決め方、注記付き範囲の中身の落ち、入れ子の取り違え
  - 題名 `<h1>`、文書末尾の `<br />`、7 行以上あるヘッダの扱い
  - 外字が Unicode を持つ場合に画像ではなく文字で出す（プレビューの軽量化）

## [0.1.0] - 2026-07-26

最初のリリース。

- CodeMirror 6 のエディタ（セマンティックハイライト・診断・ホバー・`［＃` の補完・
  ブロックの折りたたみ・見出しジャンプ）
- リアルタイム HTML プレビュー（ON/OFF 切り替えと手動更新つき）
- ファイルのドラッグ＆ドロップ
- 開く／保存（Shift_JIS・UTF-8 の自動判別）
- HTML をクリップボードへコピー
- 日本語／英語の UI
- macOS（dmg）／ Windows（nsis）向けビルド
