## 概要

- **役割**: 注記記号の入れ子を再帰下降で認識し、`Token` 列にする。
- **意味解釈はしない**: コマンド `［＃…］` の中身は不透明な文字列のまま。傍点か見出しか等の
  解釈・前方参照・カギカッコ解釈は後段（parser / resolver）。
- **決定的**: 記号の入れ子（`《》`・`｜…《》`・`※［…］`・`〔…〕`・`［＃…］`）は決定的にパース。
- **位置つき**: 全トークンが行内の絶対 char span を持つ（入れ子含む）。
- **2 段構成**: `｜`（明示ルビ前置）は字句走査では**単なるマーカー**として出すだけ。親文字の
  確定は直後の畳み込みパス `fold_prefixed_ruby` が行う（後述）。字句走査自体を単純に保つため。

## 入力と出力

- **入力**: 1行のテキスト（改行を含まない文字列）。
- **出力**: `Token` の列。各 `Token = { kind: TokenKind, span: [start, end) }`。
- **処理単位**: 行ごとに独立（行をまたがない）。
- **位置単位**: **char（Unicode スカラ）単位**。byte ではない（全角も1と数える）。

## 入口（公開 API）

- `tokenize(input) -> Vec<Token>` … **通常の入口**。トップレベルとして走る
  （＝未閉じ `〔` を行末まで延長する。下記「未閉じ構文の扱い」）。
- `tokenize_collecting_unclosed_accents(input) -> (Vec<Token>, Vec<Span>)` …
  `tokenize` と**完全に同一のトークン列**に加え、未閉じアクセントの span を返す。
  診断 `unclosed-accent` 用で、**トークン列は変わらない**（byte 一致に無影響）。
- `Tokenizer::new_top_level(input)` ＋ `.tokenize()` … 上記2つの下位。通常は使わない。
- `tokenize_children(content, base)` … **内部専用**。入れ子内容を絶対位置つきで再帰処理する
  （`allow_unclosed_accent = false` で走る）。

**入力は 1 行**（改行を含まない文字列）。複数行を渡すと `\n` はただのテキストになり、
未閉じ `〔` の「行末まで」が「入力末まで」に変わるため、呼び手が行分割してから渡す。

## トークン種別（`TokenKind`）

- `Text(String)` … 通常テキスト
- `Ruby { children }` … ルビ `《…》`（親文字は直前の Text 側）
- `PrefixedRuby { base_children, ruby_children }` … 明示ルビ `｜親文字《ルビ》`
- `Command { content }` … コマンド `［＃…］`（中身は生文字列）
- `Gaiji { description, had_igeta }` … 外字 `※［…］`
- `Accent { children }` … アクセント分解 `〔…〕`
- `RubyPrefix` … `｜` の**一時マーカー**（字句走査が出す）。畳み込みパスで `PrefixedRuby` に
  なるか、余れば `Text("｜")` に戻る。**`tokenize()` の出力には現れない**（中間段階専用）。

## 状態

- `chars` … 入力を char 配列にしたもの
- `pos` … 現在位置（char インデックス）
- `base` … この断片が**元の行の何文字目から始まるか**（入れ子を絶対位置にするオフセット。トップレベルは 0）
- `allow_unclosed_accent` … 未閉じ `〔` を許すか（**トップレベルの行のみ true**、入れ子は false）
- `unclosed_accent_spans` … 未閉じのまま行末まで延長したアクセントの span を溜める
  **検証用の副産物**。トークン列には一切影響しない（`tokenize_collecting_unclosed_accents`
  が返し、診断 `unclosed-accent` が使う）。入れ子では未閉じ `〔` がリテラルなので溜まらない。

## デリミタ文字

**開始記号**（`read_text` はこれらに当たると区切る＝ここからディスパッチが働く）:

- `［`（COMMAND_BEGIN） / `《`（RUBY_BEGIN） / `｜`（RUBY_PREFIX） /
  `※`（GAIJI_MARK） / `〔`（ACCENT_BEGIN）

**閉じ記号・補助記号**（各リーダの内部でのみ意味を持ち、単独では**本文**になる）:

- `］`（COMMAND_END） / `》`（RUBY_END） / `〕`（ACCENT_END） / `＃`（IGETA）

---

## 全体ループ

`tokenize()` は **走査ループ → 畳み込みパス** の2段からなる。

1. **走査ループ**: `pos` が終端に達するまで繰り返す:
   1. `start = pos` を記録
   2. `next_token()` で1トークンの**種別**を読む（`pos` が進む。実体は下の各リーダ関数）
   3. `Token { kind, span: [base+start, base+pos) }` を出力に積む
2. **畳み込みパス**: 走査で得たトークン列に `fold_prefixed_ruby` を1回かけ、`｜` の一時
   マーカー `RubyPrefix` を直後のルビと畳んで `PrefixedRuby` にする（下記「畳み込みパス」節）。
   `tokenize_children` 経由でも走るので入れ子も同じ規則で畳まれる。

## ディスパッチ（`next_token`）

現在の文字で分岐し、対応する**リーダ関数**（`read_*`、手続きは次節）へ委譲する。
デリミタでなければテキストを読む。

| 先頭文字 | 条件 | 委譲先（リーダ） |
|---|---|---|
| `［` | 次が `＃` | `read_command` |
| `［` | それ以外 | 1文字進めて `Text("［")` |
| `《` | — | `read_ruby` |
| `｜` | — | 1文字進めて `RubyPrefix` マーカー（親文字確定は後段 fold） |
| `※` | 次が `［` | `read_gaiji` |
| `※` | それ以外 | 1文字進めて `Text("※")` |
| `〔` | — | `try_read_accent`（失敗なら 1文字進めて `Text("〔")`） |
| 上記以外 | — | `read_text` |

---

## 各リーダの手続き

ディスパッチ表の各リーダ関数の中身。いずれも `pos` を進め、1トークンの種別を返す。

### テキスト（`read_text`）

- **開始記号**（`［ 《 ｜ ※ 〔`）に当たるまで読み進める。閉じ記号では区切らない。
- その区間を `Text` にする。

### コマンド（`read_command`）→ `Command { content }`

- `［＃` を読み飛ばす。
- **対応する `］` まで**読む（`［ ］` のネスト深さを数える）。
- 中身の文字列を `content` として保持し、閉じ `］` を読み飛ばす。
- **中身の意味は一切解釈しない**（後段 parser の仕事）。
- `］` が無い場合 → 「未閉じ構文の扱い」節。

### ルビ（`read_ruby`）→ `Ruby { children }`

- `《` を読み飛ばし、`》` まで読む（**ネストは見ない**＝最初の `》` で閉じる）。
- 中身が空（`《》`）なら `Text("《》")` にする（参照実装の挙動）。
- そうでなければ中身を**再帰的にトークナイズ**して `children` にする。
- `》` が無い場合 → 「未閉じ構文の扱い」節。

### 明示ルビ前置 `｜`（字句走査）→ `RubyPrefix` マーカー

- `｜` は字句走査では**1文字進めて `RubyPrefix` マーカーを出すだけ**。親文字の範囲は決めない。
- 親文字の確定は下の**畳み込みパス**が行う。これにより字句走査は「記号を刻むだけ」で済む。

### 畳み込みパス（`fold_prefixed_ruby`）→ `PrefixedRuby { base_children, ruby_children }`

- `tokenize()` の**最後に一度だけ**走る（`tokenize_children` 経由でも呼ばれ、入れ子も畳む）。
- **後方規則**: ルビ（暗黙 `Ruby`）を見つけたら、トークン列を**末尾から遡り**、別のルビ
  （`Ruby`/`PrefixedRuby`）を越えない範囲で**最も近い `RubyPrefix`** を探す。
  - 見つかれば「そのマーカー〜ルビ直前」を**親文字**として `PrefixedRuby` に畳む（親文字は空でもよい）。
  - 見つからなければ暗黙ルビのまま（親文字は後段 `resolve_ruby_bases` の文字種抽出に委ねる）。
- **余った `RubyPrefix` は本文の `｜`（`Text`）へ戻す**（span はそのまま＝`｜` 1文字分）。
  これにより「`《》` の前に `｜` が複数あれば最後の `｜` が親文字開始、それより前はリテラル」が従う。
- **コマンド透過は自動**: `［＃…］` は既に1トークンなので、その中の `｜` はマーカーにならず、
  親文字の区切りに数えられない。
- **畳んだ `PrefixedRuby` の span** は「マーカー `｜` の span **∪** ルビの span」（＝`｜` から `》` まで）。
  走査ループが付ける `[base+start, base+pos)` では表せない、**fold が合成する唯一の span**。
  `base_children` / `ruby_children` の各トークンは元の絶対 span を保つ。

### 外字（`read_gaiji`）→ `Gaiji { description, had_igeta }`

- `※［` を読み飛ばす。
- 次が `＃` なら読み飛ばして `had_igeta = true`（無ければ `false`）。
- 対応する `］` まで読み（ネストを数える）、中身を `description` にする。
- 閉じ `］` を読み飛ばす。
- `］` が無い場合 → 「未閉じ構文の扱い」節。

### アクセント（`try_read_accent`）→ `Accent { children }` または「失敗」

- `〔` を読み飛ばし、`〕` を探す（`found_close`）。
- **失敗して `〔` をリテラルにする条件**:
  - `〕` が見つからず、かつ**トップレベルでない**（入れ子）。
  - 中身が **`ACCENT_TABLE` の並び**（`e'` 等）を**含まない**。
- 通れば、`〕` があれば読み飛ばし、中身を**再帰的にトークナイズ**して `children` にする。
- トップレベルで `〕` が無い場合は、中身が記号を含む限り**行末まで**をアクセント内容とする。
  このとき当該 `〔…` の span を検証用に控える（`tokenize_collecting_unclosed_accents` で取得。
  トークン列自体には無影響で、診断 `unclosed-accent` が使う）。

## 未閉じ構文の扱い（閉じ記号が行内に無い場合）

**巻き戻して literal にするのは `〔`（入れ子のとき）だけ**。他はすべて**行末まで飲み込む**。

| 記法 | 閉じ記号が無いとき | 結果 |
|---|---|---|
| `《…` | `》` なし | **行末まで**をルビ内容に → `Ruby`（例:`あ《かな` → `Text(あ), Ruby(かな)`） |
| `［＃…` | `］` なし | **行末まで**を `content` に → `Command`（例:`あ［＃注記` → `Text(あ), Command(注記)`） |
| `※［…` | `］` なし | **行末まで**を `description` に → `Gaiji`（例:`あ※［＃外字` → `Text(あ), Gaiji(外字)`） |
| `〔…`（**トップレベル**） | `〕` なし | **行末まで**をアクセント内容に（中身依存判定は通す）→ `Accent`。span を控える |
| `〔…`（**入れ子**） | `〕` なし | **巻き戻して** `Text("〔")`（1文字だけ進み、残りは通常トークナイズ） |

- `［＃` / `※［` の閉じ探索は**ネスト深さを数える**（`skip_until_balanced`）。深さが 0 に戻らない
  まま終端へ達した場合も、上表のとおり行末までを中身として**受理する**（拒否しない）。
- `《` の閉じ探索は**ネストを見ない**（最初の `》` で閉じる）。
- 閉じ記号 `］ 》 〕` が**単独で**現れた場合は `read_text` の区切りではないので、**ただの本文**になる
  （例:`あ》い` → `Text("あ》い")`、`あ〕い` → `Text("あ〕い")`）。

---

## 入れ子と span（絶対位置）

- ルビ・アクセントの中身は、**開始 char 位置を `base` として渡した**サブトークナイザで
  再帰処理する（`tokenize_children(content, base + 内容の開始位置)`）。
- 明示ルビの**親文字**は、`｜`〜`《` の間の**通常トークン列**がそのまま `base_children` になる
  （畳み込みパスが束ねるだけ）。個々のトークンは元の絶対 span を保つ。
- これにより**入れ子のトークンも行内の絶対 char span を持つ**。
- サブトークナイザは `allow_unclosed_accent = false`（入れ子では未閉じ `〔` を許さない）。

## 性質まとめ

- **行ローカル・char 単位・再帰下降**。
- **コマンドの中身は不透明**（意味解釈は後段）。
- **全トークンが絶対 char span を持つ**（入れ子含む）。合成されるのは fold が作る
  `PrefixedRuby` の span のみ。
- **入力を拒否しない**。未閉じ構文は行末まで飲み込むか literal に戻すかで、必ず何らかの
  トークンになる（巻き戻すのは入れ子の `〔` だけ）。
- **外部知識への依存は 1 つだけ**: アクセントの中身判定が参照する `ACCENT_TABLE`
  （`accent_table.json` 由来の有限テーブル 72 件）。他は記号の形だけで決まる。
